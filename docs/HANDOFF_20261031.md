## 当前融合的确切定义

同一540条验证记录先按id、y对齐；现有7个候选模型验证分数上做三成员0.05步长网格，以及约20000次随机权重探索，得到观察到的最高63.148%：

`scores = .15 * qwen8b_step1530_logits + .25 * qwen14b_step135_logits + .60 * qwen8b_step675_logits`

每行argmax为最终类别。原参数不修改；保持18个类别列顺序一致。现有脚本未完整保存随机搜索种子和搜索轨迹，因此63.15%应称本次搜索最佳观察值，不能称全局最优。融合文件位于 fusion_best_20261031。与14B单模型61.48%比较增加1.67个百分点；同一验证集被反复用来挑数据/步数/权重，结果有选择偏差，不能等同线上分数。

Kaggle notebook 依次执行三个旧推理脚本，保存完整logits，再做上述精确融合。它检查测试id与类别顺序相同。三个独立子进程退出后释放显存，T4按序推理。ATLAS与CPU特征尚未加入。
